# 基于ELF2RK3588的边缘AI多模态设备巡检智能运维系统

## 项目简介
本项目为参加飞凌嵌入式（ELFBOARD）相关赛事的开源作品。
本系统采用阿克曼转向结构车模为载体，基于“**RK3588 上位机 + STM32G431 下位机**”双脑协同架构，深度集成了 ROS2 导航与端侧多模态大模型技术，致力于解决工业复杂环境下的自主巡检与设备运维难题。

## 🌟 核心特性
- **端侧大模型视觉研判**：充分发挥 RK3588 的 NPU 算力，本地部署 Qwen3-VL 多模态大模型，实现零样本（Zero-Shot）的异常目标检测。
- **本地 RAG 知识库检索**：整合 ONNX 轻量化语义模型，将实时画面与工业 5S 安全标准深度结合，生成高准确率的智能化巡检报告。
- **物理级断电与定时唤醒**：底层单片机通过 PMOS 与 SW3518S 快充芯片握手，为ELF2提供 100W PD 冗余供电，并支持 RTC 硬件级定时自动唤醒与断电休眠，极大提升长期部署的续航能力。
- **阿克曼高频运动闭环**：底层 STM32 以 1000Hz 频率解算 IMU 数据，结合 ROS2 Nav2 导航栈实现极其平滑的定点巡航。
- **防“变砖” OTA 升级**：针对偏远无网环境，定制底层 Bootloader，实现连续启动异常自动回滚机制。

## 📂 仓库目录结构
本项目包含了系统的全部设计文件与代码：
- `1_ROS2_Workspace/`：上位机核心控制逻辑，包含导航配置、巡检大模型调用（`patrol_commander.py`）、系统监控等。
- `2_STM32_Code/`：下位机主控单片机固件及防砖 Bootloader 源码工程。
- `3_RAG_Knowledge_Base/`：本地化的工业巡检安全规范 Markdown 知识库。
- `4_Documentation/`：项目的完整《嵌入式设计说明书》。
