# 工业车间 5S 安全巡检与隐患判定手册

为了确保语义检索匹配，本手册按“看到的场景”分类。当视觉模型看到以下物体时，请严格对应以下判定标准。

## 【场景：地面有纸箱、纸板、气泡膜、包裹等包装物】
- **现象描述**：在地面、走廊或通道上看到纸箱、废旧纸板、气泡膜、包装袋、快递包裹等。
- **隐患判定**：需根据状态区分。
  - **状态1：整齐堆叠**。如果纸箱是完好的且整齐堆叠在指定区域或靠墙摆放，【判定为正常】，不构成违规。
  - **状态2：散落/随意丢弃/被气泡膜包裹**。如果是单个散落、破损、或与气泡膜等废弃物混杂，【明确判定为异常】！属于【5S定置违规】及【火灾/绊倒隐患】。工业标准要求废弃包装材料必须放置在回收区。
- **处理建议**：若散落，记录“地面存在散落的纸箱/包装物，违反5S管理标准，存在火灾及绊倒隐患”，建议立即清理；若整齐堆叠，则无需处理。

## 【场景：地面有散落的水瓶、饮料瓶等】
- **现象描述**：在地面看到倒置或散落的透明塑料水瓶、黑色水瓶、饮料瓶等。
- **隐患判定**：【明确判定为异常】！属于【5S定置违规】及【滑倒/绊倒隐患】。水瓶随意丢弃在地面可能导致作业人员踩踏滑倒，如果是倒置或未盖紧还可能引发液体泄漏。
- **处理建议**：记录“发现地面有散落/倒置的水瓶，存在滑倒隐患”，建议立刻由保洁或5S专员清理回收。

## 【场景：地面有袋子、防静电袋、塑料袋】
- **现象描述**：在地面看到蓝色袋子（如蓝色防静电屏蔽袋）、黑色袋子、塑料包装袋等零散包装物。
- **隐患判定**：【防静电物料违规存放】及【跌倒/滑倒隐患】。电子元器件的蓝色防静电袋对静电和粉尘极其敏感，掉落或放置在未经处理的普通地面会导致芯片击穿报废。
- **处理建议**：在巡检日志中紧急标记“发现特种包装袋/蓝色袋子遗落或违规着地”，建议立刻由专业人员回收至防静电作业台。

## 【场景：地面有办公椅、凳子、推车等家具】
- **现象描述**：在通道或作业区地面看到孤立的办公椅、白色小凳子、手推车等，且周围无作业人员。
- **隐患判定**：【设备未归位】。所有移动式作业家具（椅子、凳子）在人员离开时必须推入工位桌下或靠墙归位。停留在通道中属于严重的5S违规。
- **处理建议**：在巡检日志中记录“发现办公椅/凳子未按规定归位”，建议通知区域负责人整改。

## 【场景：地面有电线、线缆、网线】
- **现象描述**：在地面看到黑线、白线、电源线、网线等线缆横跨地面。
- **隐患判定**：【绊倒隐患 (Trip Hazard)】及【违规临时接线】。车间地面严禁走明线。
- **处理建议**：记录“地面发现裸露线缆，存在绊倒人员及触电风险”。

## 【场景：地面有水渍、油渍、黑色污渍】
- **现象描述**：地面颜色异常，看到液体反光、黑色不明污渍。
- **隐患判定**：【滑倒隐患 (Slip Hazard)】及【潜在设备漏油/漏水】。
- **处理建议**：高危风险，记录“地面存在疑似油渍/水渍的黑色污渍”，建议立即安排保洁清理并排查漏水源头。
