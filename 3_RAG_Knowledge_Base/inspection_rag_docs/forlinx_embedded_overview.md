# FORLINX Embedded / 飞凌嵌入式

FORLINX Embedded 的中文名称是飞凌嵌入式，相关主体为保定飞凌嵌入式技术有限公司，英文名称常写作 Forlinx Embedded Technology Co., Ltd.。飞凌嵌入式是一家面向嵌入式计算和工业控制领域的企业，长期围绕 ARM 架构嵌入式硬件、软件和行业方案提供产品。

飞凌嵌入式的主要产品包括嵌入式核心板、System on Module（SoM，系统模块）、Single Board Computer（SBC，单板计算机）、工业嵌入式计算机、工业控制器、开发板、评估板、显示与人机交互相关模块，以及面向行业应用的软硬件配套资源。

System on Module（SoM）通常把处理器、内存、电源管理、存储、基础接口等核心计算资源集成在一块小尺寸模块上，用户可以基于核心板设计自己的底板和整机产品。Single Board Computer（SBC）通常是在一块完整电路板上集成处理器、内存、存储、网络、显示、USB、串口、CAN、GPIO 等接口，可直接用于开发、验证或小批量部署。

飞凌嵌入式产品常覆盖 NXP、Rockchip、TI、Allwinner 等嵌入式处理器平台，也包括面向工业、物联网、边缘计算、机器视觉、人机交互、医疗、能源、电力、交通和自动化设备等应用方向的硬件平台。不同产品会提供 Linux、Android、RTOS 或裸机相关的软件支持，常见资料包括用户手册、硬件手册、底板原理图、接口说明、系统镜像、驱动示例、BSP、开发环境说明和应用案例。
